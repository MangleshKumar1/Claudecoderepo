# TripMates (working name)

A travel community platform: discover and pin beautiful places, share trips, find people going to the same destination, and (later) plan and book everything in one place.

- Full plan, features, competitors, costs and validation strategy: [docs/PLAN.md](docs/PLAN.md)
- Demand-test landing page (static, no backend): [landing/index.html](landing/index.html)

Status: pre-MVP. Rule #1: validate demand before building the full app.
